# out/

Результаты генерации. Для каждого прогона `--out out/<имя>`:

| Файл | Что внутри |
|---|---|
| `<имя>_report.txt` | проверка по СП (✓/!/✗), принятые сечения, отметки, ведомость |
| `<имя>_bom.csv` | ведомость пиломатериалов: наименование, сечение, длина, шт, м³ |
| `<имя>_members.json` | все элементы каркаса с координатами — для своей постобработки |
| `<имя>.blend` | сцена Blender с коллекциями по конструктивным группам |
| `<имя>_<ракурс>.png` | рендер (iso / front / side / top) |

Папка перезаписывается при каждом прогоне с тем же `--out`.
