# karkas-sp31105

Параметрический генератор деревянного каркаса дома для **Blender** по
**СП 31-105-2002** «Проектирование и строительство энергоэффективных одноквартирных
жилых домов с деревянным каркасом».

Спецификация в JSON → каркас платформенного типа в Blender + **проверка соответствия нормам**
+ ведомость пиломатериалов. Таблицы СП (включая все 14 таблиц пролётов Приложения Б)
переведены в машиночитаемый вид, сечения подбираются автоматически.

Поставляется как [skill для Claude Code](#как-skill-для-claude-code), но работает
и как обычный Python-пакет.

---

## Быстрый старт

```bash
git clone https://github.com/eugene-chernyshenko/karkas-sp31105
cd karkas-sp31105
K=.claude/skills/karkas-blender

# проверка по нормам + ведомость, без Blender (секунды)
python3 $K/scripts/build_house.py --spec dom_9x7 --out out/dom --check

# геометрия, .blend и рендеры
blender -b --python $K/scripts/build_house.py -- \
    --spec dom_9x7 --out out/dom --render --views iso,front,side,top
```

Правки без файла спецификации:

```bash
python3 $K/scripts/build_house.py --check --out out/d \
    --set plan.length=10 --set plan.width=8 --set snow_kpa=2.0 \
    --set roof.slope=1:1.71 --set stud_spacing=400 --set storeys=2
```

Зависимостей нет: `rules.py` / `model.py` — чистый Python 3.11+, `bpy` нужен только
для построения геометрии. Проверено на Blender 4.5 LTS.

## Что получается

| Файл | Содержание |
|---|---|
| `_report.txt` | проверка по СП (✓ / ! / ✗), принятые сечения, отметки, ведомость |
| `_bom.csv` | ведомость пиломатериалов: наименование, сечение, длина, шт, м³ |
| `_members.json` | все элементы каркаса с координатами — для своей постобработки |
| `.blend` | сцена с коллекциями по конструктивным группам |
| `_<ракурс>.png` | рендер: iso / front / side / top |

Каждый объект Blender несёт custom properties `kind`, `section`, `length_m` и `sp_note` —
ссылку на пункт СП, по которому элемент поставлен.

## Что строится

| Коллекция | Элементы | Пункты СП |
|---|---|---|
| `00_Фундамент` | схематичная лента | табл. 5-1, 5.4.7 |
| `01_Перекрытие_1` | опорная доска 38×88, обвязочные и крайние балки, балки, составной прогон, колонны, горизонтальные связи, чёрный пол | 6.2.1, 6.2.6, 6.2.8, 6.2.9 |
| `02_Стены_1` | нижняя обвязка, двойная верхняя обвязка, стойки, угловые стойки-нашивки, перемычки 2×(38×h) с прокладкой, опорные и крайние стойки проёмов, укороченные стойки, подоконные доски | 7.2.1–7.2.15 |
| `03_Внутренние_стены` | несущие стены и перегородки | 7.2, 6.3 |
| `10_Крыша` | стропила, балки чердачного перекрытия (затяжки), коньковая доска, стойки фронтонов, обвязка стропил по карнизу; либо кровельные балки плоской крыши | 8.2–8.4 |

До 3 этажей, двускатная или плоская крыша.

## Что проверяется

- **4.2.1** — этажность, высота этажа, шаг стоек, доля проёмов ≤ 30 % площади каждой
  несущей стены, снеговая нагрузка ≤ 3,0 кПа.
- **Табл. 7-1** — сечение / шаг / свободная высота стоек по виду стены и воспринимаемой
  нагрузке. Сечение крупнее табличного при том же шаге проходит (таблица задаёт минимум).
- **Табл. Б-1…Б-3** — пролёты балок перекрытий и чердачного перекрытия.
- **Табл. Б-4…Б-7** — кровельные балки и стропила по снеговой нагрузке.
- **Табл. Б-8…Б-11** — составные прогоны (с интерполяцией по грузовой площади) и коньковые балки.
- **Табл. Б-12…Б-14** — перемычки, с учётом жёсткой обшивки и нагрузки на стену.
- **Табл. 8-1** — допустимость сочетания «уклон / шаг стропил / снег» и число гвоздей в узле.
- **8.2.1.3** — ширина дома ≤ 9,8 м и шаг стропил ≤ 600 мм для применимости таблиц.
- **6.2.4** — шаг балок ≤ 600 мм.
- **Табл. 5-1, 6-2, 6-3, 7-3, 8-6** — фундамент, чёрный пол, обрешётка, обшивки, кровельный настил.

Справочно (геометрию не меняет): вентиляция крыши 8.7, анкеровка 6.2.8.4, опирание
перегородок 6.3, пожарные требования табл. 7-4, люк на чердак 8.8.

Пример строки отчёта:

```
✓ [крыша/стропила] 38x184 @ 600 мм, пролёт 3.50 м ≤ 4.41 м (табл. Б-6, снег 1.5 кПа)
✗ [крыша/область применения] ширина дома по пролёту стропил 11.00 м > 9,8 м —
  таблицы Б-6/Б-7 неприменимы (8.2.1.3), требуется расчёт
```

## Расчёты без модели

```python
import sys; sys.path.insert(0, ".claude/skills/karkas-blender/scripts")
from karkas import rules as R, build_house, report

R.pick_joist(4.2, 400)                      # '38x235'
R.rafter_max_span("38x184", 600, 1.5)       # 4.41
R.pick_lintel(1.8, "roof", snow_kpa=2.0)    # высота перемычки, мм
R.girder_max_span("4x235", 3.3, storeys=1)  # интерполяция по грузовой площади
R.check_stud("38x140", 600, 2.5, "external", "attic+1")

res = build_house({"plan": {"length": 10.0, "width": 8.0}, "snow_kpa": 2.0})
print(report(res)); res.errors
```

## Ограничения

Не генерируются: вальмовые крыши, ендовы, слуховые окна, мансардные стены, стропильные
фермы, эркеры и консоли (6.2.10), проёмы в перекрытии (6.2.11), лестницы (раздел 12).
План только прямоугольный. Обшивки, утеплитель, пароизоляция и облицовка не строятся
геометрией — выдаются только требуемые толщины. Нормы по всему перечисленному есть
в `references/`, моделировать нужно вручную.

**Это не замена расчёту.** Инструмент применяет табличные решения СП в границах их
применимости и честно сообщает, когда выходит за них. За этими границами нужен
поверочный расчёт по СНиП II-25 / СП 64.13330.

## Структура

```
SP-31-105-2002.pdf                      оригинал свода правил (46 чертежей узлов)
docs/sp31105-full.txt                   полный текст для grep (маркеры ===== PAGE N =====)
.claude/skills/karkas-blender/
    SKILL.md                            формат спецификации, что проверяется, ограничения
    references/01..06-*.md              выжимка норм по разделам + все таблицы Приложения Б
    scripts/karkas/rules.py             таблицы СП в коде + подбор сечений
    scripts/karkas/model.py             spec -> каркас + отчёт о соответствии
    scripts/karkas/geom.py              элемент каркаса (брус)
    scripts/karkas/build.py             построение в Blender, камера, рендер
    scripts/build_house.py              CLI
    scripts/selftest.py                 самопроверка таблиц и генератора
    examples/dom_9x7.json               рабочий пример
```

Самопроверка сверяет ~35 контрольных значений прямо из таблиц СП и собирает эталонный дом:

```bash
python3 .claude/skills/karkas-blender/scripts/selftest.py
```

## Как skill для Claude Code

```bash
# во всех проектах сразу
cp -r .claude/skills/karkas-blender ~/.claude/skills/

# или один источник правды
ln -s "$PWD/.claude/skills/karkas-blender" ~/.claude/skills/karkas-blender
```

Дальше достаточно сказать «построй каркас 10×8, снег 2 кПа, двускатка 1:2» — skill
подхватится сам. Каталог скилла самодостаточен и работает из любого места.
