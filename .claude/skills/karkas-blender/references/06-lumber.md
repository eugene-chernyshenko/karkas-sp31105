# Сортамент пиломатериалов и соглашения модели

## Сечения, встречающиеся в СП 31-105-2002 (мм, строганый пиломатериал)
Толщины: **18/19, 38, 64, 89**
Ширины: **38, 64, 89, 140, 184, 235, 286**

Рабочий набор:
| Обозначение | Применение в СП |
|---|---|
| 38x38 | связи/распорки, бруски под настил и стыки |
| 19x38, 19x64, 19x89 | обрешётка потолка (табл. 6-3), горизонтальные связи, связи ферм, обрешётка под облицовку |
| 18x88 (≥) | диагональные связи жёсткости наружных стен (7.2.5) |
| 38x64 | стойки малонагруженных стен (табл. 7-1) |
| 38x89 | стойки, затяжки, опорные доски, распорки под перегородки, нижняя опорная доска (38x88) |
| 64x89 | усиленные стойки (табл. 7-1) |
| 38x140 | стойки наружных стен, коньковая балка (8.2.3.1) |
| 38x184 / 38x235 / 38x286 | балки перекрытий, стропила, элементы составных прогонов и перемычек |

Составные элементы: `n x (38 x h)`, n = 2…5, h ∈ {89, 140, 184, 235, 286}.
Перемычки — **2х(38xh)** (или один брус 89xh), прогоны и коньковые балки — 3х/4х/5х.

## Соглашения геометрической модели (используются в `scripts/karkas/`)
- Единицы в Blender — **метры**; в спецификации сечения задаются в **мм** строкой `"38x140"`.
- Оси: **X** — длина дома, **Y** — ширина, **Z** — вверх.
- Нулевая отметка Z = **верх фундамента / низ нижней опорной доски**.
- Начало координат (0, 0) — **наружный угол каркаса** (наружные грани каркасных стен).
- `width` / `length` в плане — по **наружным граням каркаса стен** (не по облицовке).
- Первое число сечения — **толщина** (38), второе — **высота/ширина** (140).
  - для стойки: 38 вдоль стены, 140 поперёк стены (= толщина стены), если не указан `flat: true`;
  - для обвязки: 38 по вертикали, 140 поперёк стены;
  - для балки/стропила: 38 по горизонтали поперёк пролёта, 235 по вертикали (на ребро).
- Стойки раскладываются **по осям** с шагом `stud_spacing` от наружной грани стены;
  крайние стойки — по краям стены, промежуточные — по сетке, как в реальной раскладке плит
  обшивки (кратно 400/600 мм от угла).
