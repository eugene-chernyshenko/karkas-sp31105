Проверь конструкцию по СП 31-105-2002, используя skill `karkas-blender`. Blender не нужен.

Запрос пользователя: $ARGUMENTS

Если это точечный вопрос про один элемент (пролёт балки, стропила, перемычки, стойки,
прогона, коньковой балки) — ответь функциями из `karkas.rules`, не собирая дом целиком:

```python
import sys; sys.path.insert(0, "<каталог скилла>/scripts")
from karkas import rules as R
```

Если это дом целиком — собери спецификацию и запусти `build_house.py ... --check`.

В ответе обязательно: конкретные цифры, номер таблицы и пункта СП, по которым получен
вывод, и запас (например «3,50 м ≤ 3,72 м по табл. Б-1»). Если параметры выходят за
границы применимости таблиц (4.2.1, 6.2.4, 8.2.1.3) — скажи об этом прямо: там нужен
поверочный расчёт, а не табличное решение.
